# 小鲸桌面宠物 3.12.1

喝茶改为一只手全程托住茶碟，另一只手握杯柄举杯饮茶，再把茶杯放回手中的茶碟。每轮动作约8秒，之后托着杯碟休息约12秒、偶尔眨眼，再开始下一轮；日常两轮后自然收动作。连续工作时仍约15分钟喝一次，只喝一轮，期间电脑淡出让杯碟完整露出，结束后在原位置和角度恢复。42套天气、节日与节气服装均使用独立握杯和托碟素材。

验收：右键“一起摸鱼”，分别选择吹泡泡、一起钓鱼、喝一口茶。先将鼠标移开观看完整动作，再移回人物头部观察收动作与抬头过渡。钓鱼时可单击右侧抖动的红色浮漂；靠近浮漂不会取消钓鱼。工作开始、抓起和退出时会妥善结束当前动作并保存已确认的鱼。

本版改进：走回右下角时先转向侧身，两腿交替迈步、手臂反向摆动，停稳后转正。42 套实际服装各有独立侧身素材。吹泡泡、喝茶、翻书和其他摸鱼动作加入连续动作；泡泡采用独立动态绘制，不再保留原图中的静止泡泡，并加强深浅背景上的边缘、高光和填充。鼠标回到角色上时，先收动作，再平滑抬头看向你；钓鱼时靠近浮漂不会收杆，靠近头部才会抬头。翻页只在书本页边内绘制，移除了原先的白色方块。

验收建议：右键“一起摸鱼”分别选择吹泡泡、喝茶、翻翻书，将鼠标先移开再移回头部；再把角色抓到屏幕左侧松手，遇到自由下落后观察侧身走回。松手仍随机选择飞行或自由下落，可重复几次。吹泡泡在浅色和深色桌面上均可观察。

松手时等概率随机选择：展开小龙翼飞回默认地点，或双手按住裙摆自由下落、站稳后自己走回。默认地点是当前所在屏幕可用区域的右下角，避开任务栏，并随角色大小调整。所有原天气、节日、节气服装和47套独立飞行素材保留。

保持整个文件夹完整，解压后双击 **XiaoJingDesktopPet.exe**。要求 Windows 10/11 x64 和 .NET Framework 4.8，无需 Python、Node 或开发工具。

## 操作

- 已移除转身扭尾巴交互及对应菜单；角色原本的鲸鱼尾巴与其他动作保留。
- 回家途中可再次按住提起；摸头、喂食或手动小互动会暂停走路，结束后继续。Codex 开始任务不会打断回家，回到默认地点再恢复电脑工作。睡眠/休眠恢复后沿用已选动作，不重新随机。
- 本版已移除旅游景点、随机景点及位置调整功能；旧版景点设置会被忽略，名称、天气所在地、其他开关和鱼缸收藏继续保留。
- 单击头部：眯眼蹭手、冒爱心；7秒内连续摸三次会脸红。单击与双击会自动区分，单击后稍等片刻即可看到反应。
- 在角色区域按住约0.2秒提起，拖动鼠标移动；快速移动会惊讶。每次松手随机选择一次飞行或自由下落，各约一半概率，不按拖动距离强制切换。飞行沿弧线转向、减速落到屏幕右下角；自由下落时双手捂住裙摆，双腿后收、两侧带气流，到当前屏幕地面后缓冲站稳，再迈步走回右下角。走路有加速和减速，不会横向瞬移。
- 双击投喂：伸手接食、鼓腮咀嚼、手持纸巾擦嘴、满足，约4.4秒。节日/节气使用对应食物；普通酷热天气喂冰棒，并有冰凉反应。
- Codex开工时拉好电脑继续打字；确认任务结束后合上电脑、举起双臂伸懒腰。连续工作约15分钟会喝口茶。新任务开始会立即恢复工作，读取未知不当作工作结束。 开工、喝茶和合盖期间始终使用已确认的电脑背盖样式，不再闪现旧的正面小电脑。
- 空闲时随机钓鱼、吹泡泡、看书、抱靠垫打盹。鼠标靠近会抬头看你；夜间更容易犯困，风天会追落叶、雨天会接雨，节日有专属小互动。右键“一起摸鱼”可立即选择动作，“随机摸鱼与生活习惯”可开关自动动作。
- 钓鱼：右键“一起摸鱼 → 一起钓鱼”，等待浮漂抖动并出现感叹号，在约3秒内单击浮漂。钓到的六种小鱼会自动保存，右键“查看我的鱼缸收藏”查看；工作时先等任务结束再玩。
- 心情和饱腹度显示在右键菜单底部；摸头、投喂、钓鱼会改善心情，饱腹度和心情随时间缓慢下降，偏低时更倾向安静休息。数据自动保存在本机，不会因未照顾而产生惩罚。
- 所有互动沿用当前日常、天气、节日和节气服装；抓起、喂食等手部动作中，会暂时收起扇子或手持节日摆件。

- 双击喂食；右键切换 Codex 额度 / 硬件状态。启动时默认回到屏幕右下角，右键“返回屏幕右下角”也可手动飞回。
- 普通日子喂鱼，酷热时喂冰棒；节日分别喂饺子、汤圆、青团、粽子、巧果、月饼、重阳糕、腊八粥、南瓜饼和姜饼人。
- 右键“节日装扮”自动按北京时间换装，也可手动预览十套服装。节日外观优先，不叠加天气服装或天气粒子；天气数据文字仍显示实际天气。圣诞礼物分布在角色左右两侧，角色遮住靠近身体的部分礼物。
- 所有日常、天气和节日服装均有循环待机动作。普通日子随天气及严重程度变化，节日造型保持固定。
- Codex 执行任务时显示“工作中”，小鲸穿着当前服装在电脑前工作；Codex 打开但没有执行任务时显示“摸鱼中”；Codex 退出后显示“睡眠中”。后两种状态保留当前待机动作。拖动、喂食优先播放，之后恢复工作动作。
- 右键“修改宠物名称…”可自定义名称；右键“设置天气所在地…”可搜索城市并选择结果。
- 新增二十四节气服装、每套四帧循环待机和对应食物。默认只在北京时间的节气当天自动换装，传统节日优先，其他日期继续使用天气服装；节气服装固定，不叠加天气造型。右键“二十四节气装扮”可按春夏秋冬预览、恢复自动或关闭。手动预览优先于自动日期。
- 节气食物包括春饼、荠菜馄饨、梨、春菜饼、青团、香椿拌豆腐、立夏蛋、苦菜饼、青梅糕、凉面、藕粉羹、绿豆汤、西瓜、百合粥、桂圆银耳羹、芝麻汤圆、芝麻糕、柿子、饺子、糍粑、烤红薯、汤圆、糯米饭和八宝饭，采用民俗与当季食材灵感搭配，并非各地统一习俗。
- 右键“随机摸鱼与生活习惯”和“开机自启”都会明确显示“已开启／已关闭”，开启时还有勾选标记；点击即可切换。随机摸鱼开关会记住选择。开机自启默认关闭，开启后在Windows登录时启动当前安装的桌宠；移动文件夹后需重新开启。若开机自启状态读取失败，会单独显示，避免误认为关闭。

## Codex 任务状态与额度

只打开聊天、尚未发起任务的完整初始化记录按空闲处理，显示“摸鱼中”；开始任务后显示“工作中”，完成后恢复“摸鱼中”。真实读取失败或未写完整的首条任务事件仍会显示状态未知。

长时间使用或恢复旧聊天后，会继续跟踪当前这次会话的任务记录；较早的历史记录不会覆盖续接后的工作或完成状态。

任务状态约每 3 秒检查一次，通过只读的本地任务生命周期与会话写入锁判断，包括本机桌面任务和子任务。另检查当前 Windows 会话内的 Codex 桌面进程，用于区分“摸鱼中”和“睡眠中”，支持当前进程名为 ChatGPT.exe 的商店版；普通 ChatGPT 和 Codex 命令行后端不会算作桌面应用。新版本会跳过无活动写锁的历史记录，隔离个别被占用的文件，保留已完整写入的任务状态，不会因为下一条消息尚未写完就变成未知；也不再因历史文件超过 2000 个而停止监测。右键“立即刷新工作状态”会重新读取任务记录；“立即刷新全部状态”也包含工作状态，读取期间点击会排队继续处理。云端、远程或没有写入本地事件的任务不在监测范围内；无法确认时仍显示状态未知，并在“查看数据来源与状态”中列出原因。

额度使用当前电脑已登录的 Codex 账户，约每 2 分钟尝试读取。需要在本机安装并登录 Codex；本分享包不含任何登录凭据、个人额度快照、个人配置或聊天内容。

## 天气与硬件

天气默认浙江绍兴诸暨，可通过右键搜索所在地。结果包含区域和国家，用于区分同名城市；选择并确认后才更换地点。搜索失败不会改变原设置。天气来自 Open-Meteo，每 10 分钟更新；风、雨、雪、晴各有轻、中、重三档。断网保留同一地点最近数据并标注缓存，切换地点后不会沿用其他城市的数据。

节气采用北京时间民用日期。2026—2028 年的 72 个日期来自并核对[香港天文台公历与农历对照表](https://www.hko.gov.hk/en/gts/time/conversion.htm)，其他 1901—2100 年使用太阳视黄经计算日期。节气当日从北京时间 00:00 换装，次日恢复日常天气造型（遇节日则穿节日服装）。

硬件每 5 秒刷新。CPU 优先尝试现有 ASUS ACPI 驱动接口，再读取已启用导出的 AIDA64（包括图吧便携版）或可选传感器助手。已移除旧的“启用 CPU 温度传感器…”菜单和启动提示窗口，ASUS 自动读取方式保留。GPU 直接调用本机 NVIDIA 驱动自带的 NVML 接口，每次读取后释放查询资源，不再反复启动 nvidia-smi.exe。无需另装温度程序或随包附带驱动；没有 NVIDIA 显卡或接口不可用时显示不可用。内存为物理内存占用。备用 CPU 助手与 AIDA64 连接步骤见 sensors 目录，不自动安装驱动。

关机、注销、睡眠或休眠时自动暂停硬件、天气、额度和 Codex 工作状态的后台查询，取消网络请求并结束桌宠自己启动的额度查询辅助进程。已打开的地点搜索也会取消；不会关闭 Codex 桌面程序或你的任务。关机时不等待查询锁，个人设置照常保存。唤醒后恢复定时刷新，并重新获取数据；休眠前的未完成结果不会覆盖新状态，地点搜索可手动重试。

## 分享、升级与卸载

分享整个便携压缩包，接收者读取自己电脑上的账户和硬件数据。settings.ini 是运行后生成的本机设置，分享时不要附带。

升级前从桌宠托盘菜单退出旧版，保留自己的 settings.ini，解压新版完整覆盖程序和素材。卸载前取消“开机自启”，退出程序，再删除解压文件夹。自启只使用当前用户的 Windows Run 项，没有系统服务。

src 包含源码；Rebuild.ps1 可使用 Windows 自带 C# 编译器重新编译。assets 中包含美术及生成提示词，sensors 中保留第三方许可。
