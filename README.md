## 操作

- 单击头部摸头；短时间连续摸头会害羞。按住人物约 0.2 秒提起，拖动移动，快速拖动会惊讶。
- 松手时随机选择一次：展开龙翼沿弧线飞回当前屏幕右下角，或双手按住裙摆下落、缓冲站稳后侧身走回。飞行有起飞、转向和收翼落地过渡。默认地点避开任务栏。
- 自动散步与走回家均使用侧身步态，两腿交替、手臂反向摆动，并有转身与停步过程。可从右键菜单开关自动散步。
- 双击退出当前闲暇并投喂：伸手接食、送到嘴边、咀嚼、擦嘴和满足。节日、节气换成相应食物；酷热天气喂冰棒。
- 右键“一起摸鱼”选择吹泡泡、钓鱼、喝茶、看书或打盹。鼠标经过不会中断；单击其他闲暇场景中的人物身体，会收动作并抬头。
- 吹泡泡：握棒蘸水，举到嘴边吹出动态泡泡，再放回瓶边。喝茶：一手托茶碟，另一手举杯饮茶，放回杯碟后休息约 12 秒再喝。
- 钓鱼：坐在小船上甩竿，浮漂抖动并出现感叹号时单击人物或浮漂；收鱼后取下鱼钩、捧鱼放入鱼篓。鱼只计入一次，右键查看六种小鱼收藏。
- 接雨有动态落雨和掌心水花；翻页局限在书页内。随机摸鱼会根据时间、天气与心情选择日常动作，可单独关闭。
- 右键切换“1 显示 Codex 剩余额度”与“2 显示硬件状态”，每次只显示一种。
- 右键可修改宠物名称、搜索天气所在地、调整大小、置顶和开机自启。随机摸鱼与开机自启都明确显示“已开启／已关闭”。自启默认关闭；移动文件夹后需要重新开启。

## 工作与换装

Codex 执行任务时，小鲸侧坐在小龙旁使用浅紫电脑，在看着屏幕思考与敲键盘之间循环。工作开始时两只小龙伴随星雾出现；结束后收手、星雾淡出，再伸懒腰。连续工作约 15 分钟会喝一轮茶，再恢复电脑场景。拖动、投喂等互动优先，之后恢复工作。

Codex 打开且空闲显示“摸鱼中”，退出后显示“睡眠中”；确实无法确认时显示“状态未知”，不会误当作任务结束。工作状态约每 3 秒检查一次，读取本机 Codex 任务生命周期、写入锁与桌面进程。远程任务或未写本地事件的任务可能无法确认。右键可手动刷新，并查看数据来源。

天气服装按风、雨、雪、晴与严重程度变化。普通大风通过更快、更明显的头发、衣袖、龙翼与尾巴摆动，以及落叶、花瓣表现。节日装扮优先于天气，节气默认只在北京时间的当天换装；节日或节气装扮固定，不叠加天气造型或天气粒子。右键可手动预览。圣诞礼物分列左右，并由角色遮住靠内侧一小部分。

十个节日为春节、元宵、清明、端午、七夕、中秋、重阳、腊八、万圣节和圣诞节。节气食物采用民俗及当季食材灵感，并非各地统一习俗。2026—2028 年节气日期沿用已核对的香港天文台日历数据，其他 1901—2100 年使用太阳视黄经计算。

本版不含洗澡、变身、扭尾巴或旅游景点功能。

## 天气、额度与硬件

天气默认浙江绍兴诸暨；右键“设置天气所在地”可搜索并选择城市。来自 Open-Meteo，每 10 分钟更新；断网时保留同地点最近数据并标注缓存。切换地点后不会使用其他城市的缓存。

额度约每 2 分钟读取当前电脑已登录的 Codex 账户。分享包不含登录信息、个人额度快照、聊天记录或个人设置。接收者使用自己电脑上的账户。

硬件每 5 秒刷新。CPU 优先使用已有 ASUS ACPI 驱动接口，再尝试已导出的 AIDA64 或可选传感器助手；不同电脑能否读取取决于已有驱动和传感器接口。GPU 直接调用 NVIDIA 驱动的 NVML，读取后释放，不再反复启动 nvidia-smi。无支持接口时显示不可用。内存为物理内存占用。sensors 中包含可选 CPU 助手、说明与第三方许可，不自动安装驱动。

关机、注销、睡眠和休眠时暂停硬件、天气、额度和工作状态查询，取消网络请求，并结束桌宠自己启动的额度查询辅助进程；不会关闭 Codex 或用户任务。唤醒后恢复刷新并拒绝休眠前过期结果。

## 分享、升级与卸载

分享完整便携压缩包。首次运行后会在本机产生 settings.ini 和缓存，重新分享时不要附带这些个人文件。

手动升级前先退出旧版，将个人 settings.ini 复制到新解压文件夹，再运行新版；新旧版本不要同时运行。不要把旧 assets 混入新版。卸载前关闭“开机自启”，退出程序，再删除解压文件夹。自启只使用当前用户的 Windows Run 项，没有系统服务。

src 包含源码；Rebuild.ps1 使用 Windows 自带 C# 编译器重新编译。package-manifest.json 列出内容文件与 SHA256，压缩包旁提供整包校验值。
